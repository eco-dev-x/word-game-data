How to build an anagram solver

The trick: sort a word's letters and every anagram gets the same key. LISTEN, SILENT and TINSEL all become eilnst. Build a map from key to words once, and each lookup is instant.

Why not try every arrangement?

A 10-letter word has 10! = 3,628,800 arrangements, and most of them aren't words. Sorting the letters costs a few microseconds and turns the search into one dictionary lookup.

JavaScript

const key = (w) => [...w.toLowerCase()].sort().join('');
const index = new Map();
for (const w of words) {                      // words: your word list
  const k = key(w);
  index.set(k, [...(index.get(k) ?? []), w]);
}
const anagrams = (w) => index.get(key(w)) ?? [];
anagrams('listen');  // ['elints', 'enlist', 'inlets', 'listen', 'silent', 'tinsel']

Python

from collections import defaultdict
index = defaultdict(list)
for w in words:
    index[''.join(sorted(w))].append(w)
anagrams = lambda w: index[''.join(sorted(w.lower()))]

Shorter words and blanks

To find every word that fits inside a rack (not just exact anagrams), compare letter counts instead: a word fits if it needs no letter more often than the rack has it, and each shortfall can be covered by a blank tile. That's how a rack word finder works; you can try one at thewordfinder.io's anagram solver.
