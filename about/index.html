About

Word Game Data is made by David James, who runs thewordfinder.io, a free word finder with daily puzzle hints and browser word games. This project publishes the underlying data openly so anyone can check it or build on it.

Sources

  • Word lists: ENABLE (public domain), with words flagged as offensive removed.
  • Wordle answers and allowed guesses: the everyday-word answer pool used by thewordfinder.io's Wordle Unlimited (1,574 answers, 8,613 allowed guesses).
