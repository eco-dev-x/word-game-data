Vowel-heavy openers like ADIEU and AUDIO feel productive but leave far more answers: consonants and their positions do most of the narrowing. A readable write-up with second-guess advice and a worked example is on thewordfinder.io: best Wordle starting words, measured.

Method

For an opener g, group the 1,574 answers by the colour pattern g would show against each. If a group has n answers, every answer in it leaves n candidates, so the average is Σn² / N. "Worst case" is the largest group; "≤10 left" is the share of answers whose group has 10 or fewer. Colours follow the game's rule for repeated letters (greens first, then yellows from the letters left).

function pattern(guess, answer) {
  const res = [0, 0, 0, 0, 0], left = {};
  for (let i = 0; i < 5; i++)
    if (guess[i] === answer[i]) res[i] = 2;          // green
    else left[answer[i]] = (left[answer[i]] ?? 0) + 1;
  for (let i = 0; i < 5; i++)
    if (res[i] === 0 && left[guess[i]] > 0) { res[i] = 1; left[guess[i]]--; } // yellow
  return res.join('');
}
